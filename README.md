## 🇬🇧 English Description

**MarkItDown Studio** is a universal document, image, and audio-to-Markdown conversion suite built with modern web technologies and a high-performance .NET 10 WPF desktop engine.

### 🌟 Key Features:
- **Comprehensive Format Support:** PDF (with OCR for scanned books), Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), CSV/TSV, JSON, HTML, Audio Transcription (Speech-to-Text), ZIP, and source code.
- **Universal Multi-AI Engine:** Seamless integration with Google Gemini, Groq AI (500+ tok/s), OpenAI GPT-4o, Anthropic Claude 3.7, DeepSeek R1/V3, and local Ollama.
- **Smart Model Fallback:** Automatically switches to secondary models upon rate limits (HTTP 429) to ensure uninterrupted conversions.
- **AI Proofreader & Formatting Review:** One-click review of OCR text, grammar, tables, and Unicode character corrections.
- **Obsidian Ready:** Produces clean, elegant Markdown files structured for knowledge management and note-taking apps.
- **Trilingual Interface:** English, Uzbek, and Russian.

## 🇷🇺 Описание на русском

**MarkItDown Studio** — универсальный инструмент для преобразования любых документов, таблиц, сканированных PDF, изображений и аудиофайлов в чистый и структурированный формат Markdown (`.md`).

### 🌟 Основные возможности:
- **Все форматы:** PDF (включая сканы с OCR), Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), CSV/TSV, JSON, HTML, Аудио транскрипция, Архивы ZIP и файлы исходного кода.
- **Мульти-ИИ интеграция:** Google Gemini, сверхбыстрый Groq AI, OpenAI GPT-4o, Anthropic Claude 3.7, DeepSeek, локальный Ollama.
- **Автоматическое переключение (Fallback):** При исчерпании лимитов модель автоматически переключается на резервную.
- **Проверка и исправление с помощью ИИ:** Быстрый поиск и исправление орфографических ошибок, битых таблиц и кодировок.
- **Поддержка 3 языков:** Русский 🇷🇺, Узбекский 🇺🇿, Английский 🇬🇧.

## 💻 Desktop Application Setup (.NET 10)

```bash
# Clone the repository
git clone https://github.com/aka-FinGo/MarkItDown-Studio.git
cd MarkItDown-Studio/dotnet

# Build and run standalone WPF application
dotnet run --project src/MarkItDown.App/MarkItDown.App.csproj
```
